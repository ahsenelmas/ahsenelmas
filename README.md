## 🚀 Featured Projects

### 🚌 Kraków Transit AI Assistant

RAG-based conversational assistant for public transport questions using GTFS, GTFS-Realtime, vector search and LLM-based query routing.

### 🤖 Agentic Internship Coordinator

AI-powered internship coordination system using FastAPI, LangGraph, PostgreSQL, n8n and automated decision workflows.

### 🎓 ATA RAG Assistant

Multilingual university chatbot using web scraping, embeddings, PostgreSQL with pgvector and retrieval-augmented generation.

### 🧑‍💻 Student Management System

Full-stack student management application using Spring Boot, PostgreSQL and React.
